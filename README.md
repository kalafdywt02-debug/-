# 🎨 تبدیل عکس به هنر اسکی در ترموکس

اسکریپتی ساده و تعاملی برای تبدیل عکس به ASCII Art در ترموکس (Termux).
فقط آدرس عکس را وارد می‌کنی، سایز و رنگ را انتخاب می‌کنی و خروجی را می‌گیری.

## ✨ امکانات

- انتخاب عکس با وارد کردن آدرس
- تنظیم عرض (سایز) خروجی، یا تنظیم خودکار با عرض صفحه
- خروجی ساده یا رنگی
- معکوس کردن روشنایی
- پشتیبانی از فرمت‌های JPG، PNG، WebP، GIF و BMP (فرمت‌های غیر JPG/PNG خودکار تبدیل می‌شوند)
- سه نوع خروجی: نمایش در ترموکس، فایل متنی txt، فایل رنگی html

## 📋 پیش‌نیازها

1. برنامه Termux (بهتر است از F-Droid نصب شود)
2. اجازه دسترسی به حافظه گوشی
3. بسته‌های jp2a و imagemagick

برای نصب پیش‌نیازها این دستورها را اجرا کن:

</div>

pkg update && pkg upgrade -y
pkg install git jp2a imagemagick -y
termux-setup-storage
<div dir="rtl">

> بعد از دستور آخر، پیام درخواست دسترسی ظاهر می‌شود. روی Allow بزن.

## 🚀 نصب و اجرا

</div>

git clone https://github.com/USERNAME/REPO.git
cd REPO
bash ascii-art.sh
<div dir="rtl">

یا اگر خواستی اسکریپت را مستقیم اجرا کنی:

</div>

chmod +x ascii-art.sh
./ascii-art.sh
<div dir="rtl">

## 🧭 نحوه استفاده

بعد از اجرا، اسکریپت به ترتیب این موارد را می‌پرسد:

| مرحله | سوال | توضیح |
|:---:|---|---|
| ۱ | آدرس عکس | مثال: ~/storage/pictures/photo.jpg |
| ۲ | عرض | عدد وارد کن (مثلاً 60) یا Enter بزن تا خودکار تنظیم شود |
| ۳ | رنگی باشد؟ | y برای رنگی، n برای ساده |
| ۴ | معکوس کردن روشنایی | y برای معکوس، n برای حالت عادی |
| ۵ | نوع خروجی | 1 نمایش، 2 فایل txt، 3 فایل html |

### 📁 آدرس عکس‌ها در گوشی

| محل عکس | آدرس |
|---|---|
| گالری / دوربین | ~/storage/dcim/Camera/photo.jpg |
| پوشه Pictures | ~/storage/pictures/photo.jpg |
| پوشه Downloads | ~/storage/downloads/photo.jpg |

برای دیدن لیست فایل‌های یک پوشه از ls استفاده کن، مثلاً:

</div>

ls ~/storage/pictures
<div dir="rtl">

### 📐 سایز پیشنهادی

- نمایش در ترموکس روی گوشی: عدد ۴۰ تا ۶۰
- ذخیره در فایل برای چاپ یا اشتراک‌گذاری: عدد ۸۰ تا ۱۵۰

### 💾 محل ذخیره خروجی

فایل‌ها در پوشه Downloads گوشی ذخیره می‌شوند و نام آن‌ها به این شکل است:

</div>

ascii_20260101_120000.txt
ascii_20260101_120000.html
<div dir="rtl">

اگر پوشه Downloads در دسترس نباشد، فایل در پوشه Home ترموکس ذخیره می‌شود.
برای دیدن خروجی رنگی، فایل html را در مرورگر گوشی باز کن.

## 🖥️ نمونه اجرا

</div>

آدرس عکس: ~/storage/pictures/cat.jpg
عرض (Enter = خودکار): 60
رنگی باشد؟ (y/n) [n]: y
معکوس کردن روشنایی؟ (y/n) [n]: n

خروجی:
  1) فقط نمایش در ترموکس
  2) ذخیره به صورت متن (txt)
  3) ذخیره به صورت HTML (برای رنگی)
انتخاب [1]: 3

✅ ذخیره شد: /data/data/com.termux/files/home/storage/downloads/ascii_20260101_120000.html

## 🛠️ رفع مشکلات رایج

| مشکل | راه حل |
|---|---|
| فایل پیدا نشد | آدرس را بررسی کن و با ls مطمئن شو فایل همان‌جاست |
| jp2a: command not found | دستور pkg install jp2a -y را اجرا کن |
| magick: command not found | دستور pkg install imagemagick -y را اجرا کن |
| پوشه storage وجود ندارد | دستور termux-setup-storage را اجرا کن و دسترسی را تأیید کن |
| رنگ‌ها درست نمایش داده نمی‌شوند | خروجی را به صورت html ذخیره کن و در مرورگر ببین |
| تصویر خیلی بزرگ یا به‌هم‌ریخته است | عرض را کمتر کن، یا ترموکس را در حالت افقی (landscape) باز کن |
